# File Inventory — AutoML-Agent Reliability Study

Every file that backs the experiment, grouped by role. The study lives entirely
in the `experiment/` package; it imports the **unmodified** AutoML-Agent code but
changes none of it. Paths are relative to the repository root.

Total committed on branch `experiment/reliability-study`: **448 files** (code + data
+ results + evidence tree). The trained-model binaries generated incidentally during
runs (`experiment/models/`) are deliberately **not** committed.

---

## 1. Harness code — the 8 Python modules (`experiment/*.py`, 1,778 lines)

| File | Lines | What it does |
|------|------:|--------------|
| [`experiment/config.py`](../config.py) | 265 | **Single source of truth.** The one full-strength config, the model/backend roster, the 6 dataset specs, task→metric map, every filesystem path, the per-backend throttle, and `grid_cells()` which expands the model × dataset × rep grid. |
| [`experiment/build_datasets.py`](../build_datasets.py) | 204 | Deterministically builds the 6 tabular CSVs (seed 42) and writes `datasets/manifest.json` recording the exact provenance of each. |
| [`experiment/baselines.py`](../baselines.py) | 158 | Computes classical "floor" scores per dataset (majority-class accuracy/F1; mean-predictor RMSE; KMeans ARI/NMI) → `baselines.json`. These are the yardstick for the semantic "runs-but-wrong" check. |
| [`experiment/instrumentation.py`](../instrumentation.py) | 126 | **The core trick.** Logging-only monkey-patches: (a) wraps `execute_script` to archive every generated script + append a ledger record; (b) a transport-layer throttle on LLM calls. Changes no agent logic. |
| [`experiment/run_grid.py`](../run_grid.py) | 403 | **The orchestrator.** Dual-mode: parent iterates the grid, launching each cell as its own watched subprocess (30-min tree-kill watchdog), classifies infra-vs-code, and is resumable; child runs exactly one cell. |
| [`experiment/analyze.py`](../analyze.py) | 436 | Reads the ledger + status + baselines and computes all five measures with Wilson 95% CIs, the error taxonomy, and the semantic check → `summary.json`, `tables.md`, and 3 figures. |
| [`experiment/report.py`](../report.py) | 176 | Renders the auto-generated paper-ready `results/report.md` from `summary.json`. |
| [`experiment/__init__.py`](../__init__.py) | 10 | Package marker (distinct from the pre-existing `experiments/` package). |

## 3. Raw evidence (written during the run)

| Path | Count / size | Role |
|------|-----|------|
| `experiment/ledger.jsonl` | **309 records**, 505 KB | One JSON line per execution attempt: cell id, attempt #, exit code, SHA-256, token usage, and the tail of the execution log. **This is the primary dataset.** |
| `experiment/runs/cell_status.json` | 39 cells, 154 KB | One record per cell: final state, outcome, attempts archived, provider markers, `infra_error` flag, money/timers. |
| `experiment/runs/run_meta.json` | 1 KB | Reproducibility metadata: snapshot date, AutoML-Agent git commit, config, model ids, prompt-template SHA-256 hashes, start time. |
| `experiment/runs/<model>/<dataset>/rep<N>/attempt_NN.py` | **309 scripts** | Every generated script, archived verbatim (even the broken ones). |
| `experiment/runs/<model>/<dataset>/rep<N>/console.log` | 39 dirs | Full stdout/stderr of the cell's subprocess. |
| `experiment/runs/<model>/<dataset>/rep<N>/cell_spec.json` | 39 | The exact cell definition that was run. |
| `experiment/runs/<model>/<dataset>/rep<N>/cell_result.json` | ≤39 | The child's own result record (absent for cells killed before writing). |
| `experiment/runs/<model>/<dataset>/rep<N>/requirements.json` | 39 | The AutoML-Agent `user_requirements` JSON handed to that cell. |

The 39 cell directories = 36 roster cells (2 models × 6 datasets × 3 reps) + 3 infra-excluded probe cells (gemini/groq/openrouter).

## 6. External code the harness depends on (unmodified AutoML-Agent)

The harness touches these existing files **at runtime only** — it imports and
monkey-patches them, never edits them:

| Path | How the harness uses it |
|------|-------------------------|
| `agent_manager/` (`AgentManager`) | Built once per cell with the full-strength config; `initiate_chat(prompt)` is the entry point. |
| `operation_agent/` (`execute_script`) | The function the instrumentation wraps to capture every execution. Patched at **both** `operation_agent.execute_script` and `operation_agent.execution.execute_script`. |
| `configs.py` (`AVAILABLE_LLMs`, model-id env vars) | Reads `AMLA_LLM` + the per-backend model-id env var **at import time** to select the LLM. |
| `prompt_pool/tabular_{classification,regression,clustering}.py` | The task prompt templates, hashed into `run_meta.json` for reproducibility. |
| `data_agent/retriever.py`, `model_agent/retriever.py` | Skipped by setting `source="user-upload"` and `model=[]` in `user_requirements`, so no external retrieval fires. |
| `openai.resources.chat.completions.Completions.create` | Patched by the throttle to space out LLM calls (timing only). |
