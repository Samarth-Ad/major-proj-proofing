# Pragmatic requirements file for the Docker image.
#
# The project's original requirements.txt is a kitchen-sink listing kept for
# paper-reproducibility; it includes ghost packages (autogpt, helm, submission,
# sklego==0.0), GPU-only packages (vllm), mismatched torch/torchaudio/torchvision
# versions, and duplicates that make a clean pip install impossible.
#
# This file installs:
#   1. What the AutoML-Agent framework itself needs at runtime
#      (openai client, pandas/numpy, bs4, dotenv, etc.).
#   2. Common ML libraries the LLM-generated code reaches for
#      (sklearn, torch CPU, catboost, xgboost, lightgbm, matplotlib, seaborn,
#       joblib, scipy, gradio, optuna, pyarrow, etc.), so the demo progresses past
#       "import error" failures into richer runtime failures.
#
# Deliberately omitted (heavy / broken / GPU-only / not needed for the demo):
#   autogluon, metagpt, autogpt, helm, submission, sklego, vllm, keras/tensorflow*,
#   simpletransformers, deepctr_torch, EasyTSAD, tsaug, segmentation_models_pytorch,
#   spacy, torch_geometric, trl, peft, shap, mlflow, kaggle, langchain*, arxivloader,
#   google_search_results, huggingface_hub (installed transitively), dataset.
